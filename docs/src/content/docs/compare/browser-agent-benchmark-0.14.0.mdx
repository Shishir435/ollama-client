# Browser Agent Benchmark: Ollama Client 0.14.0 and Nanobrowser

**Status: interim results.** Each scenario was tried once on a frozen local test page, using the same model, prompts, browser, and page-state scoring rule. Nanobrowser has saved results for 24 of 31 scenarios. Chromium returned OS `EAGAIN` (`resource temporarily unavailable`) while launching the first missing scenario. The following two multi-tab attempts produced no task results during extension/profile startup, and the final four scenarios have no saved records.

## Run setup

- **Model:** codex/gpt-6-luna, medium reasoning effort.
- **Endpoint:** the same local Ollama Client olc OpenAI-compatible service for both products (http://127.0.0.1:8083/v1).
- **Ollama Client candidate:** commit [f588c013](https://github.com/Shishir435/ollama-client/commit/f588c0136f322d514d24c829bc7d4d61f66bc57e).
- **Nanobrowser:** source [commit 24a14b76](https://github.com/nanobrowser/nanobrowser/tree/24a14b76e14a9c30fd84878ca7985049d1e7d064), built locally from its lockfile; upstream version string 0.1.13.
- Nanobrowser’s Planner and Navigator both used the same model and medium reasoning effort. Its vision settings were enabled for the canvas tasks; analytics were disabled in the test profile.
- The task pages are deterministic synthetic fixtures. Each product had one try per task, so this run does not measure repeatability or broad real-world browsing.

The saved benchmark records include the page-predicate result and terminal status for each attempted scenario. They do not preserve a detailed cause for every predicate failure; the task table reports what the evidence supports.

## Nanobrowser benchmark practices

At the tested Nanobrowser revision, its [README](https://github.com/nanobrowser/nanobrowser/blob/24a14b76e14a9c30fd84878ca7985049d1e7d064/README.md) describes a multi-agent Planner/Navigator workflow and configurable models/providers. Its [package scripts](https://github.com/nanobrowser/nanobrowser/blob/24a14b76e14a9c30fd84878ca7985049d1e7d064/package.json) include build and end-to-end testing commands. We did not find a first-party public benchmark suite or published score table in those sources at that revision.
